# Olive Leaf Blinds – homepage (React + Vite)

    npm install
    npm run dev      # local preview
    npm run build    # production build in /dist

Structure
- src/styles.css            all CSS (colours are variables at the top of the file)
- src/App.jsx               page shell + mouse-tilt effect
- src/components/           Hero, Marquee, Collection, FabricsBand, Process, Reach, Contact, Footer

Brand colours: olive (--o1 … --o9), gold (--g, --g2, --g3).
Placeholders to replace: footer phone number and email in Footer.jsx.
